# История изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версионирование: [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-08

Первый публичный выпуск. Перевод завершён на 100 % клиентской части.

### Добавлено

- **Перевод интерфейса**: 58 пространств имён, 2615 строк — вся пользовательская
  копия, которую отдают клиентские плагины DeepSeek Harness.
- **Языковой пакет** `dsh-locale-ru`: регистрирует язык `ru` с откатом на `en`
  через публичный сервис локализации, без патча самого приложения.
- **Установщик одним файлом** `install-standalone.ps1`: языковой пакет встроен
  внутрь, структура папок не требуется.
- **Установщик из папки** `tools/install.ps1` и удалятель `tools/uninstall.ps1`.
- **Аудит безопасности** `tools/audit-bundle.js`: проверяет отсутствие сетевого
  доступа, исполнения кода из строки, работы с файлами и хранилищем, а также
  отсутствие утечек и посторонних данных в репозитории.
- **Проверка контракта** `tools/verify.js`: язык, набор пространств имён, ключи,
  плейсхолдеры.
- **Воспроизводимая сборка**: `tools/build.js` даёт побайтово одинаковый бандл,
  поэтому опубликованный артефакт можно сверить с исходниками.
- **CI** `.github/workflows/verify.yml`: сборка, сверка артефакта, контракт,
  аудит — на каждый push и pull request, с правами только на чтение.
- **Документация**: `README.md`, `SECURITY.md`, `CONTRIBUTING.md`,
  `docs/how-it-works.md`, `docs/install.md`, `docs/glossary.md`,
  `docs/publish.md`.

### Решения по переводу

- Термины DSH, аббревиатуры и названия продуктов оставлены латиницей, обычные
  слова интерфейса переведены; полный свод — в [docs/glossary.md](docs/glossary.md).
- `time.locale` в разделе «Расписание» переключён с `"en"` на `"ru"`, чтобы даты
  и время форматировались по-русски (в китайском словаре там `"zh-CN"`).

### Известные ограничения

- **Каталог встроенных плагинов остаётся английским.** На странице «Встроенные
  плагины» названия и описания читаются из `package.json` каждого плагина внутри
  архива приложения, а не из словарей, и из профиля не переопределяются. Это
  данные пакетов: ни у одного плагина нет карты языков, поэтому и в китайской
  локали там английский. Перевод потребовал бы правки архива приложения.
  Остальные надписи страницы переведены.
- Механизм локализации различает только формы `.one`/`.other`, поэтому для
  чисел 2–4 родительный падеж множественного числа читается неточно. Это
  ограничение фреймворка.
- Проверено на DeepSeek Harness `0.2.0-rc.2`; на другой версии часть ключей
  может остаться английской (сработает откат `ru → en`).
- Только веб-интерфейс: в консольном профиле `tui` локали нет.
