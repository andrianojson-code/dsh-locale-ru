# Установка: подробно

Краткая версия — в [README](../README.md). Здесь разобраны случаи, на которых
обычно спотыкаются.

## Перед началом

Проверьте три вещи.

**1. Приложение запускалось хотя бы раз.** Иначе папки профиля ещё нет:

```powershell
Test-Path "$env:USERPROFILE\.dsh\profiles\desktop"
```

Если `False` — запустите DeepSeek Harness, закройте и повторите.

**2. Версия приложения.**

```powershell
& "$env:LOCALAPPDATA\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd" --version
```

Пакет собран на `0.2.0-rc.2`. На другой версии он не сломается, но часть строк
может остаться английской — сработает откат на английский язык.

**3. PowerShell не от администратора.** В заголовке окна не должно быть
«Администратор». Скрипт ищет профиль у текущего пользователя, и под
администратором просто не найдёт его.

## Установка

### Один файл

1. Скачайте `install-standalone.ps1` из раздела **Releases**.
2. Если файл пришёл по сети или через мессенджер, Windows может его
   заблокировать. Правый клик по файлу → **Свойства** → внизу галочка
   **«Разблокировать»** → ОК.
3. **Закройте приложение полностью.** Правый клик по значку в области
   уведомлений (возле часов, возможно под стрелкой «▲») →
   **«Quit DeepSeek Harness»**. Проверьте, что значок исчез.
4. Откройте PowerShell в папке с файлом: **Shift + правый клик** по пустому
   месту → «Открыть окно PowerShell здесь».
5. Выполните:

   ```powershell
   powershell -ExecutionPolicy Bypass -File install-standalone.ps1
   ```

Ожидаемый вывод:

```
Профиль : C:\Users\<вы>\.dsh\profiles\desktop
плагин  : распакован в ...\plugins\dsh-locale-ru
модуль  : разложен в ...\node_modules\dsh-locale-ru
манифест: dsh-locale-ru добавлен в зависимости и в dsh.profile.bundles
язык    : в cordis.patch.yml добавлен preference: ru
проверка: lib\client.js на месте, 214055 байт
          sha256 ab7b5414...
```

Сверьте `sha256` с суммой из релиза — это подтверждает, что файл не подменён и
не повреждён.

6. Запустите приложение.

### Из архива

```powershell
git clone https://github.com/andrianojson-code/dsh-locale-ru.git
cd dsh-locale-ru
powershell -ExecutionPolicy Bypass -File install.ps1
```

Либо распакуйте релизный архив и запустите `install.ps1` из его корня.
**Распаковывайте в новую пустую папку**: некоторые распаковщики теряют
структуру каталогов, и тогда `install.ps1` не найдёт `lib\client.js` и честно
об этом скажет.

### Несколько профилей или нестандартный путь

```powershell
Get-ChildItem "$env:USERPROFILE\.dsh\profiles" -Directory          # что есть
powershell -ExecutionPolicy Bypass -File install-standalone.ps1 -ProfileDir "D:\dsh\profiles\desktop"
```

Если задана переменная `DSH_HOME`, скрипты используют её автоматически.

## Проверка результата

```powershell
& "$env:LOCALAPPDATA\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd" `
    --profile desktop --dump-config | Select-String 'locale-ru'
```

Ожидается:

```
# == dsh-locale-ru
- id: locale-ru
  name: dsh-locale-ru
```

Команда только собирает дерево профиля и сразу выходит — сервер не поднимается,
работающее приложение она не затрагивает.

## Выбор языка

Обычно русский включается сам: система сообщает браузерному движку русский язык,
и локаль выбирается по нему. Явный выбор — **Настройки → Общие → Язык →
Русский**; он сохраняется в профиле в записи `preference: ru`.

## Удаление

```powershell
powershell -ExecutionPolicy Bypass -File uninstall.ps1
```

Скрипт убирает файлы пакета, его записи в манифесте и строку выбора языка.
`cordis.patch.yml` возвращается к исходному виду — это проверено сравнением с
копией, снятой до установки.

## Если что-то пошло не так

| Симптом | Причина и что делать |
|---|---|
| Интерфейс на английском | Приложение не было закрыто полностью. Проверьте трей, выйдите через «Quit DeepSeek Harness», запустите заново. F5 не помогает |
| `выполнение сценариев отключено` | Запускайте с `-ExecutionPolicy Bypass`, как в примерах |
| `Не найдена папка профилей` | Приложение ни разу не запускалось. Запустите, закройте, повторите |
| `В пакете нет файла lib\client.js` | Архив распакован «плоско», структура потеряна. Возьмите `install-standalone.ps1` |
| Скрипт «заблокирован» | Правый клик по файлу → Свойства → «Разблокировать» |
| Приложение не запускается | `uninstall.ps1` вернёт профиль в исходное состояние |
| Кракозябры в консоли | Это только вывод консоли. Файлы пишутся в UTF-8, приложение читает их верно |
| Часть строк осталась английской | Версия приложения отличается от `0.2.0-rc.2`, либо раздел не переведён. Сработал откат `ru → en` |

## Что делать после обновления приложения

Ничего. Пакет живёт в профиле, а не в папке установки, поэтому обновление
DeepSeek Harness его не затрагивает. Исключение — если обновление пересоздаст
профиль целиком: тогда запустите установщик заново, это одна команда.
